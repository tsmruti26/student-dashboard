# Student Academic Performance Dashboard

An interactive Streamlit dashboard that analyses what affects the final maths grade of secondary-school students. It uses the UCI Student Performance dataset (395 students, 2 Portuguese schools) and helps spot at-risk students early.

The dashboard includes KPIs, sidebar filters and five Plotly visualizations (scatter plot, box plot, sunburst, absence analysis and correlation heatmap), along with key findings and recommendations.

Built with Python, pandas, Plotly and Streamlit.

Project: Data Detective Challenge, Data Visualization Techniques Laboratory (Group 5).
